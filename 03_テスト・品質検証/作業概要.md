## 1. 概要と担当ミッション
Agent 3 は、本プロジェクトの「テスト・レビュー・品質検証」を担当する専門エージェントです。
客観的かつ敵対的な視点（Adversarial Testing）から、実装コードの静的解析、ロジックテスト、境界値検証、パフォーマンス測定を実施します。

- **役割**: QAエンジニア / テスト自動化スペシャリスト
- **権限**: 読み取り専用 ＆ テストスクリプト実行（Read-only & Test）

## 3. 品質検証タスク・テスト項目

### 3.1 Python変換ツール検証
- [ ] 0x55ヘッダーおよびチェックサム計算の正確性検証
- [ ] 破損パケットや途切れデータ混入時のクラッシュ防止検証
- [ ] 出力CSVの31カラム構成およびヘッダー命名の一致検証
- [ ] Excelで開いた際の時刻列（`\t` 保護）の書式保持・文字化けなし検証

### 3.2 モバイルアプリ・データ処理検証
- [ ] StopWatch LinkLog CSVパース時の欠損値（NULL）および時速ゼロ除算防止テスト
- [ ] 高頻度センサーデータ（数万行）に対する二分探索インデックスアクセスの正確性テスト
- [ ] 関節角度計算（ゴニオメーター）の幾何学演算精度（0°〜180°）テスト

### 3.3 パフォーマンス・描画検証
- [ ] スロー再生・コマ送り時のUIスレッド60fps維持および描画遅延（33ms以内）検証
- [ ] 大容量動画の2画面同時再生時のメモリ消費量測定

## 4. 合否判定（PASS/FAIL）基準
- **PASS**: 全テストケース成功、境界値例外の完全ハンドリング、致命的パフォーマンス低下なし。
- **FAIL**: チェックサム不一致、型パースエラー、画面カクつき、クラッシュ等の検出時は直ちにAgent 2へ修正指示を発行。
