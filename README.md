# MotionSync Analytics - スポーツ動作・センサーデータ統合分析モバイルアプリ

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Flutter](https://img.shields.io/badge/Flutter-3.10+-02569B?logo=flutter)](https://flutter.dev)
[![Python](https://img.shields.io/badge/Python-3.8+-3776AB?logo=python)](https://python.org)
[![Tests](https://img.shields.io/badge/Tests-56%2F56%20Passed-brightgreen)](03_テスト・品質検証/テスト結果レポート/)

高精度な動画スロー再生・1フレームコマ送りと、ストップウォッチ計測データ（`StopWatch LinkLog` 出力CSV）および加速度センサーログ（`WITMOTION` 9軸IMU出力CSV）をミリ秒単位で完全同期し、アスリートの動作フォームおよびパフォーマンスを多角的に解析するための統合プラットフォームです。

---

## 主な機能

1. **デュアル動画再生エンジン (`media_kit`)**:
   - 1画面／2画面並列（左右・上下）／透過ゴースト（不透明度0〜100%スライダー）のシームレス切替。
   - 個別頭出し（アンロック）と同期ロック連動再生（スロー0.1x〜1.0x、1フレーム33msコマ送り）。
   - `InteractiveViewer` による2本指ピンチズーム（最大5.0倍拡大）および平行移動。
2. **センサー波形＆HUD時系列同期**:
   - 加速度（$X, Y, Z$、**合成G**）、角速度（$X, Y, Z$、**角速度合成**）、角度（$X, Y, Z$、**角度合成**）の全12系列から自由に複数選択して重畳描画。
   - 二分探索（$O(\log N)$）により、動画シークに33ms以内で追従する再生ヘッド。
   - ラップタイム、区間時速、比較Diff、リアルタイムG値ゲージのHUD表示。
3. **画面アノテーション・幾何学計測**:
   - 3点タップによるゴニオメーター（関節屈曲角・前傾角度自動計算）。
   - フリーハンドペン、直線、矢印、円、カラーパレット選択。
   - 方眼グリッドおよび鉛直プラムライン（垂線）のワンタップ重畳。
4. **実データ連携＆エクスポート**:
   - `StopWatch LinkLog` 全22カラムCSV（BOM付き、押し忘れNULL欠損安全保護）パース。
   - `WITMOTION` 31列CSV（Excel保護タブ文字 `\t` 自動ストリップ、経過ミリ秒インデックス化）パース。
   - 計測線・角度を描画した決定的フレームの静止画書き出し（PNG形式）。
   - プロジェクト分析状態（同期オフセット、描画座標、選択波形）のJSON保存・復元。
5. **スタンドアローンバイナリ一括変換ツール (Python / EXE)**:
   - WITMOTIONのバイナリログ（`.TXT`）をダブルクリックで一括CSVデコード（Python未導入PC対応）。
