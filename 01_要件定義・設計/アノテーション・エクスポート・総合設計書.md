## 1. 概要と目的
本設計書は、動作フォーム解析の最終成果物となる「アノテーション付き静止画（PNG）」「合成動画（MP4）」のエクスポート機能、および解析途中の設定（同期オフセット、描画アノテーション、読み込みファイルパス）を端末ローカルに保存・復元するプロジェクト管理機能の内部設計を定義するものです。

---

## 2. 画面アノテーション・幾何計測の強化仕様

### 2.1 アライメント・グリッド (鉛直・水平・方眼)
- **鉛直プラムライン (Plumb Line)**: 重力方向（垂直）の基準線。選手の上半身前傾やブレード角度の倒れ込みを評価。
- **水平基準線 (Horizontal Level)**: 氷面／地面に対する水平基準線。腰や肩の傾きを評価。
- **方眼グリッド (Grid Overlay)**: 画面全体に等間隔（例: 40pxピッチ）の半透明方眼を重畳。ワンタップでON/OFFトグル可能。

### 2.2 カラーパレットおよびストローク幅調整
- **視認性の高い4色**:
  - イエロー (`#FFD600`): デフォルト（高視認性）
  - シアン (`#00E5FF`): 動画A（自選手）アノテーション用
  - レッド (`#FF5252`): 動画B（比較対象）アノテーション用
  - グリーン (`#00E676`): 理想軌道・基準線用
- **ストローク幅**: 2.0px（精密線）〜 4.0px（太線強調）。

## 3. メディアエクスポートエンジン設計

### 3.1 決定的フレームの静止画書き出し (PNG形式)
- **レンダリング方式**: Flutterの `RepaintBoundary` パイプラインを採用。
- **プロセス**:
  1. `VideoViewportArea` を `RepaintBoundary` で囲む。
  2. ユーザーが「静止画保存」を押下時、`boundary.toImage(pixelRatio: 2.0)` により高解像度ビットマップへラスタライズ。
  3. `ByteData` を PNGフォーマットでエンコード。
  4. ファイル名: `MotionSync_Frame_YYYYMMDD_HHMMSS.png` として保存。

### 3.2 動画合成エクスポート (MP4形式) パイプライン
- **FFmpegフィルターパイプライン設計**:
  - 左右並列: `[0:v][1:v]hstack=inputs=2[v]`
  - 透過ゴースト: `[0:v][1:v]blend=all_mode='addition':all_opacity=0.5[v]`
  - HUD重畳: タイムスタンプおよびラップテキストの `drawtext` フィルターチェーン。

## 4. プロジェクト分析状態の保存・復元 (JSON)

### 4.1 JSONスキーマ定義
分析セッションごとに以下のJSONフォーマットで端末ローカル（`shared_preferences` または JSONファイル）に永続化します。

```json
{
  "projectId": "PROJ_20261108_0645",
  "updatedAt": "2026-11-08T06:45:00.000Z",
  "videoAPath": "C:/videos/run_a.mp4",
  "videoBPath": "C:/videos/run_b.mp4",
  "viewMode": "splitHorizontal",
  "syncOffsetSeconds": 0.60,
  "ghostOpacity": 0.50,
  "selectedWaveforms": ["accelX", "accelY", "accelZ", "accelTotal"],
  "annotations": [
    {
      "type": "angleGoniometer",
      "color": "#FFD600",
      "strokeWidth": 3.0,
      "points": [{"dx": 120.5, "dy": 200.0}, {"dx": 150.0, "dy": 310.0}, {"dx": 180.2, "dy": 420.0}],
      "calculatedAngle": 112.4
    }
  ]
}
```

### 4.2 自動復元ライフサイクル
同一動画ファイルを再度開いた際、ファイルハッシュまたはパスに基づき保存済みプロジェクト状態を自動検知し、前回の同期オフセット値や描画アノテーションをワンタップで復元可能とします。

## 5. 総合検証方針
- プロジェクト状態のJSONシリアライズ・デシリアライズの双方向完全性テスト。
- 方眼グリッド描画およびプラムラインのアライメント描画テスト。
- 全体成果物のドキュメントおよび利用マニュアルの統合。
