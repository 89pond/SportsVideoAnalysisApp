## 1. 概要と目的
本設計書は、アスリートの動作フォームおよびパフォーマンスを定量的・視覚的に比較解析するため、2つの動画（動画A: 自選手、動画B: お手本や過去データ）をミリ秒単位で連動制御する「デュアル動画同期エンジン」の内部設計を定義するものです。

---

## 2. アーキテクチャ構成

### 2.1 プレイヤーコア (media_kit) 選定理由
モバイル（iOS / Android）およびデスクトップにおいて、一般的なOS標準プレイヤー（AVPlayer, ExoPlayer）はコマ送り時にキーフレーム（Iフレーム）に吸着し、1フレーム単位の精密な頭出しが困難な場合があります。
本システムでは、オープンソースの強力な動画レンダラー `libmpv` をベースとする **`media_kit`** を採用します。
- **高精度ステップ送り**: 1フレーム単位（約16ms〜33ms）の確実なシーク。
- **超スロー再生**: 音声ピッチ補正を伴う 0.1x〜1.0x の低遅延滑らか再生。
- **デュアルインスタンス**: 単一画面内で2つの独立したプレイヤーインスタンスをメモリ競合なく同時描画。

### 2.2 デュアル動画コントローラーの責務分離
```
┌────────────────────────────────────────────────────────┐
│             DualVideoSyncController                    │
│  - 再生モード管理 (個別アンロック / 同期ロック)        │
│  - 同期オフセット (offsetB = posB - posA) 保持         │
│  - 一括コマンド発行 (play, pause, step, setRate)       │
└────────────┬─────────────────────────────┬─────────────┘
             │                             │
             ▼                             ▼
┌─────────────────────────┐   ┌─────────────────────────┐
│     Player A (動画A)    │   │     Player B (動画B)    │
│  - 自選手 / メイン動画  │   │  - 比較対象 / お手本    │
│  - media_kit インスタンス│   │  - media_kit インスタンス│
└─────────────────────────┘   └─────────────────────────┘
```

## 3. 同期制御アルゴリズムとステートマシン

### 3.1 個別アンロックモード (基準点頭出しフェーズ)
1. ユーザーは「同期ロック」を解除（個別アンロック状態にする）。
2. 動画Aをコマ送り／シークし、動作の決定的瞬間（例: スケートブレードの氷面接地、スタートの初動）で静止。
3. 動画Bを同様に操作し、動画Aと全く同じ動作基準点（接地瞬間）で静止。
4. この状態で「同期ロック」ボタンを押下。

### 3.2 同期ロックモード (連動比較再生フェーズ)
- ロック時の動画Aの再生位置 $T_A$ と動画Bの再生位置 $T_B$ から、固定オフセット $\Delta t$ を確定します。
- 以降の再生・一時停止・スロー再生・コマ送りは、両プレイヤーに対して同時にディスパッチされます。

### 3.3 タイムスタンプ・オフセット計算式

$$\Delta t = T_B - T_A$$

動画Aが位置 $t_A$ へシークされた際、動画Bの目標シーク位置 $t_B$ は次式で決定されます。

$$t_B = \text{clamp}(t_A + \Delta t, \ 0, \ \text{Duration}_B)$$

さらに、下部ツールバーのオフセット微調整ボタン（$\pm 0.01$ 秒、$\pm 0.05$ 秒）が押された場合、手動オフセット補正値 $\delta$ が加算されます。

$$t_B' = t_B + \delta$$

### 3.4 1フレーム単位の高精度コマ送りロジック
- 動画のメタデータからFPS（例: 30fps, 60fps, 120fps）を取得。
- 1フレームあたりの時間ステップ $\Delta t_{\text{frame}} = \frac{1000}{\text{FPS}} \text{ [ms]}$（30fps時は約33.3ms、60fps時は約16.6ms）。
- コマ送りボタン押下時: 一時停止状態で両プレイヤーの `position` を $\pm \Delta t_{\text{frame}}$ だけシーク。

## 4. 表示レイアウトとズーム・パン制御

### 4.1 InteractiveViewerによるピンチズーム・平行移動
- 各動画ビューポートは `InteractiveViewer` ウィジェットでラップされます。
- **機能**:
  - 2本指のピンチイン／ピンチアウトにより、最大5.0倍まで足元やブレードを拡大。
  - ドラッグによる任意位置への平行移動（パン）。
  - ダブルタップで等倍（1.0x）リセット。

### 4.2 透過ゴーストのアルファブレンディング設計
- 下層に動画A、上層に `Opacity(opacity: ghostOpacity)` で動画Bを完全同サイズでスタック配置。
- 不透明度スライダー（0.0〜1.0）により、両選手のシルエットの重なりを視覚的に直接比較。
