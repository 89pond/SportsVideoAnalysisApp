## 1. 概要と担当ミッション
Agent 2 は、本プロジェクトの「実装・コーディング」を担当する専門エージェントです。
設計書に基づき、高品質かつ堅牢なソースコードをスモールステップで作成・編集します。

- **役割**: フルスタック・エンジニア（Flutter/Dart ＆ Python データエンジニア）
- **権限**: ソースコード生成・編集（Write）

---

## 2. 担当ディレクトリ構成
実装コードは用途に応じて以下のサブディレクトリに整理して管理します。

```
    └── ...
```

## 3. 担当実装モジュール一覧

### 3.1 センサーデータ一括変換ツール (Python)
- [ ] 0x55ヘッダー検出および11バイト固定長パケット（0x50〜0x54）デコード処理
- [ ] チェックサム検証ロジック
- [ ] Excel誤認対策（`\t` タブ文字付加による文字列化）およびUTF-8 with BOM CSV出力
- [ ] フォルダ内TXTファイル一括自動処理ループ

### 3.2 モバイルアプリ本体 (Flutter / Dart)
- [ ] StopWatch LinkLog CSVパーサー（全22カラム対応、欠損値保護）
- [ ] センサーCSVパーサーおよび二分探索同期エンジン
- [ ] `media_kit` を用いたデュアル動画コントローラー（個別頭出し／同期ロック／スロー再生）
- [ ] `CustomPainter` による加速度波形・再生ヘッド追従・HUD表示
- [ ] 3点タップによる関節角度計測（ゴニオメーター）および描画ツール
- [ ] プロジェクト状態保存（JSON）および動画・静止画エクスポート機能

## 4. コーディング原則・規約
- **スモールステップ開発**: 一度に多数のモジュールを編集せず、1機能ずつ完成・検証を行う。
- **型安全・例外安全**: CSVパース時の欠損値（NULL）、ゼロ除算（Infinity/NaN）、境界値エラーを厳格に防御する。
- **オフライン完結**: クラウド送信や外部ネットワーク通信を行わず、端末ローカルで完結するコードとする。
