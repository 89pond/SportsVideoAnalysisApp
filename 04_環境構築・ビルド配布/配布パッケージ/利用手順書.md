## 1. ツール概要
本ツール（`witmotion_converter.exe`）は、WITMOTION製9軸IMUセンサーから記録されたバイナリログファイル（`.TXT` または `.txt`）を自動検出し、WinMotion互換の31列CSVファイル（`.csv`、UTF-8 with BOM）へ高速かつ一括で自動変換するWindows専用スタンドアローンプログラムです。

- **Pythonのインストールは不要** です。
- 複数のファイルを一括で自動デコードします。
- Excelで直接開いた際の文字化けや時刻（ミリ秒）欠損を100%防止する特殊保護を行っています。

---

## 2. 動作環境
- **対応OS**: Windows 10 / 11 (64bit)
- **依存ソフトウェア**: なし（単体で動作します）

## 3. ダブルクリックによる一括変換手順

1. **EXEファイルの配置**:
   - `witmotion_converter.exe` を、変換したい `.TXT` ファイル群（例: `WIT00021.TXT` 等）と同じフォルダ内にコピー（または配置）します。
2. **ダブルクリック起動**:
   - `witmotion_converter.exe` をダブルクリックして実行します。
3. **自動変換の実行**:
   - 黒い画面（コンソール）が立ち上がり、同フォルダ内の `.TXT` / `.txt` ファイルが自動検出されて一括変換が開始されます。
   ```text
   ============================================================
   WITMOTIONバイナリデータ一括CSV変換プログラム
   処理対象フォルダ: C:\path\to\sensor_data
   検出ファイル数  : 3 件
   ============================================================
   [1/3] 変換中: WIT00021.TXT ... 完了 (出力: WIT00021.csv, 24,500 行)
   [2/3] 変換中: WIT00022.TXT ... 完了 (出力: WIT00022.csv, 18,200 行)
   [3/3] 変換中: WIT00023.TXT ... 完了 (出力: WIT00023.csv, 30,120 行)
   ------------------------------------------------------------
   一括変換完了: 3/3 成功, 総出力レコード数: 72,820 行
   ============================================================
   ```
4. **終了**:
   - `[Enter]キーを押して終了してください...` と表示されたら、Enterキーを押して画面を閉じます。
   - 同一フォルダ内に同名の `.csv` ファイルが生成されています。

## 4. コマンドライン（CLI）からの実行手順
PowerShell または コマンドプロンプトから引数を指定して実行することも可能です。

- **フォルダ指定実行**:
  ```powershell
  .\witmotion_converter.exe "C:\Users\User\Desktop\センサー生データ"
  ```
- **単一ファイル指定実行**:
  ```powershell
  .\witmotion_converter.exe "C:\Users\User\Desktop\WIT00021.TXT"
  ```

## 5. 出力仕様とExcelでの利用について
- **文字コード**: UTF-8 with BOM（日本語WindowsのExcelで文字化けしません）
- **改行コード**: CRLF (`\r\n`)
- **Excel時刻保護**:
  - `Time` 列および `Chip Time()` 列の時刻文字列の先頭には、Excelの自動書式誤認（ミリ秒の丸め・消失）を防ぐため **タブ文字（`\t`）** が付与されています。
  - Excelで開くと「文字列」として認識され、`22:41:40.095` のようにミリ秒まで欠損なく正常に表示されます。

## 6. トラブルシューティング
- **「対象ファイルが見つかりませんでした」と表示される**:
  - 変換したいファイルの拡張子が `.TXT` または `.txt` になっているかご確認ください。
- **Windows Defender等の警告画面が表示される**:
  - 自作EXE初回実行時のSmartScreen警告が表示された場合は、「詳細情報」をクリックし「実行」を選択してください。
